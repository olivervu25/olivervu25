## 🔬 Featured Research & Open-Source Projects

### [λ-PSD — Scalable Approximate SNR-Optimised Polynomial Stein Discrepancies](https://github.com/olivervu25/weighted-psd)
Research code for studying scalable Stein discrepancies to assess sampling quality in Bayesian computation, with scripts for reproducing experiments and figures.  
`Python` · `Statistical Testing` · `Stein Discrepancies` · `Bayesian Computation`  
**[Explore code and experiments →](https://github.com/olivervu25/weighted-psd)**

### [Accelerated Multifidelity Simulation-Based Inference](https://github.com/olivervu25/Accelerated-Multifidelity-SBI)
Research on making Bayesian inference more computationally efficient by combining simulations of different fidelities.  
`Simulation-Based Inference` · `Bayesian Inference` · `Multifidelity Methods`  
**[Explore repository →](https://github.com/olivervu25/Accelerated-Multifidelity-SBI)**

### [rjsf — R Interface to Jump-Switch-Flow Simulation](https://github.com/olivervu25/rjsf)
An R interface to the Python **Jump-Switch-Flow** simulator, supporting hybrid stochastic–deterministic simulations for compartmental models. Developed as part of **Google Summer of Code 2026**.  
`R` · `Python` · `Scientific Computing` · `Open Source`  
**[Explore package →](https://github.com/olivervu25/rjsf)**
